## Tuairisgeul

Tha an *Joomla! Patch Tester* air a chleachdadh le Luchd-deuchainn gus dèanamh cinnteach gu bheil na pacaidean còd a chruthaich Luchd-leasachaidh a’ dèanamh na bu chòir dhaibh a dhèanamh gun bhuaidhean taobh nach eileas ag iarraidh. Tha an duilleag *Roghainnean* air a cleachdadh gus an ceangal ri Github a shuidheachadh.

### Eileamaidean Coitcheann

Tha cuid de na h-eileamaidean air an duilleag seo air an còmhdach ann an artaigilean Cuideachaidh fa leth:

* [Bàraichean-inneal](jdocmanual?article=help/common-elements/toolbars).
* [An taba Ceadan](jdocmanual?article=help/common-elements/edit-permissions).

Barrachd Fiosrachaidh: [Stiùireadh do Luchd-tòiseachaidh airson Deuchainn Bhiastagan Joomla](https://brian.teeman.net/joomla/873-a-dummies-guide-to-joomla-bug-testing)

## Mar a gheibhear thuige

- Tagh **Co-phàirtean → Patch Tester** à chlàr-taice an Rianaire.
  - Tagh am putan *Roghainnean* sa Bhàr-inneal.

## Raointean an Fhoirm

### Taba Stòras GitHub

- **Stòras GitHub** 'S e `Joomla! CMS` an roghainn bhunaiteach. Cleachd e.

### Taba Dearbhaidh Github

Feumaidh tu cunntas Github agus Token Github. Tha iad uile an-asgaidh - faic taba Dearbhaidh GitHub airson mion-fhiosrachadh.

![Taba dearbhaidh Github ann an Roghainnean Patchtester](../../../gd/images/joomla-patchtester/patchtester-options/02-github-authentication-tab.png)

- **Dòigh Dearbhaidh GitHub** Tagh an dòigh Token. Chan obraich an dòigh Teisteanasan bhon t-Sultain 2020.
- **Token GitHub** Cuir a-steach an Token a fhuair thu bho GitHub.

### Taba Roghainnean an Fhrithealaiche CI

Tha na roghainnean seo air an cleachdadh airson deuchainn fèin-obrachail. Cleachd na roghainnean bunaiteach airson deuchainn làimhe.

![Taba roghainnean frithealaiche Github CI ann an Roghainnean Patchtester](../../../gd/images/joomla-patchtester/patchtester-options/03-ci-server-settings-tab.png)

- **Seòladh an Fhrithealaiche CI** Bun-roghainn: `https://ci.joomla.org`
- **Cuir Amalachadh CI air** Bun-roghainn: Dheth
